# 🎮 圣经主题游戏中心 (Bible Game Hub)

这是一个基于纯前端技术打造的圣经主题小游戏集合大厅平台。项目采用多游戏子目录架构，玩家可以在游戏大厅挑选并体验不同类型的网页游戏。

---

## 🕹️ 收录游戏一览

### 1. 📜 天路历程：圣经棋盘巡礼 (`/pilgrim-progress`)
- **游戏类型**：多人桌面跑丁 / 益智问答
- **支持人数**：1 ~ 8 人同台
- **核心机制**：
  - 基于经典“蛇梯棋”改良的 70 站旷野朝圣之旅。
  - 内置 3D 投骰动画与微跳动步进效果。
  - 恩典阶梯（跃进）、旷野蛇陷阱（倒退）、安息日庇护所。
  - 36 张恩典与试炼卡牌事件抽取。
  - 圣经 66 卷书 280+ 道考题答题机制，答对增加信心值，答错扣减信心。
  - 同格互动（彼此祝福 / 狭路磨砺）与信心耗尽时的“禁食祷告”恢复机制。

### 2. ⛵ 七十人：使徒行传之路 (`/seventy-disciples`)
- **游戏类型**：回合制策略探索 / 模拟经营
- **核心机制**：
  - 扮演受差派的七十门徒之一，体验两两出征、受难与复活的大使命旅程。
  - 探索地中海沿岸节点航路网络。
  - 独特的“双科技树”成长系统，在地中海各大城池深耕建立教会。
